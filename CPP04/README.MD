## Description

CPP Module 04 is a C++ project that covers polymorphism, abstract classes, and interfaces. It includes three exercises:

- **ex00**: Basic inheritance and polymorphism with Animal, Dog, and Cat classes using virtual functions.
- **ex01**: Deep copy with a Brain class, ensuring proper memory management when copying objects.
- **ex02**: Abstract classes by making Animal non-instantiable.

## Instructions

Each exercise has its own directory with a Makefile. To compile and run:

```
cd ex00
make
./animal
```

Same for ex01 and ex02 (executables are `brain`).

To clean:

```
make fclean
```

Requires a C++98 compatible compiler.
