## Description

CPP Module 06 covers C++ type casting. The project explores the different cast operators in C++ (`static_cast`, `dynamic_cast`, `reinterpret_cast`) through three exercises:

- **ex00** - Scalar type conversion using `static_cast`.
- **ex01** - Serialization and deserialization using `reinterpret_cast`.
- **ex02** - Identifying real types using `dynamic_cast`.

## Instructions

Each exercise has its own directory with a `Makefile`. To compile and run:

```
cd ex00  # or ex01, ex02
make
./convert "42.0f"  # example for ex00
```
